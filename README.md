# Stylish — E-Commerce Mobile Application

**Stylish** is a modern mobile e-commerce application for fashion, clothing, and accessories. It features a clean, minimalist user interface with a sleek pink accent palette, providing a seamless user experience from registration to checkout.

---

## Key Features

- **User Authentication:** Complete login, registration, and social sign-in options (Google, Apple, Facebook), as well as a password recovery flow.
- **Onboarding Experience:** Interactive walkthrough screens guiding new users through the app's primary features.
- **Product Catalog & Browsing:** Grid view displaying products with search functionality, voice search input, sorting, filtering, discount tags, and user rating indicators.
- **Shopping Cart Management:** Interactive cart screen supporting item quantity adjustments, removal, and live price recalculations.
- **Order Placement & Checkout:** Streamlined order overview with saved delivery addresses, fee breakdowns, and multiple payment method selections (Visa, MasterCard, PayPal).
- **User Profile Management:** Dedicated profile screen allowing users to edit personal details, business addresses, and update profile avatars.

---

## Tech Stack

- **Framework:** Flutter (Dart)
- **State Management:** Provider / ChangeNotifier
- **UI Components:** Custom Styled Widgets, Material Design

---

## Application Screens

The application includes the following core screens:

1. **Splash Screen:** Minimalist brand entry layout.
2. **Authentication:** Login and Sign-Up forms with social login options.
3. **Onboarding:** Introductory slides ("Choose Products", "Get Your Order").
4. **Product Catalog:** Product list with search bar, filters, ratings, and price discounts.
5. **Shopping Bag & Checkout:** Full cart control, delivery address configuration, and payment gateway selection.
6. **User Profile:** Account and shipping address settings.
